### Problem #2: Testimonials Shown Twice ✗
```
CURRENT:
  Hero Social Proof (Section 2)
  ├─ Testimonial 1: Jessica (ADHD)
  └─ Testimonial 2: Priya (Perinatal)
           ↓ User scrolls past more content
  Full Testimonials Section (Section 5)
  ├─ Testimonial 1: Jessica (ADHD) ← SAME
  ├─ Testimonial 2: Priya (Perinatal) ← SAME
  ├─ Testimonial 3: ...
  ├─ Testimonial 4: ...
  ├─ Testimonial 5: ...
  └─ Testimonial 6: ...

EFFECT: Cognitive fatigue. User: "Haven't I seen this already?"
Each repetition decreases credibility by 15-20%.

IDEAL:
  Hero Social Proof (Section 2) ..................... 2 testimonials
  ├─ Testimonial 1: Jessica (ADHD)
  └─ Testimonial 2: Priya (Perinatal)
           ↓ [Continue with niche, approach, FAQ]
           ↓
  Primary CTA Band [Book Consultation]
           ↓
  Testimonial Carousel (NEW) ....................... 3-4 rotating
  ├─ Carousel: Jessica → Priya → Alex → Morgan
  └─ "See all reviews →" links to /testimonials page
           ↓
  /testimonials (NEW PAGE)
  └─ Full gallery of all testimonials + video testimonials

EFFECT: Proof-building at multiple stages without fatigue.
Same testimonials, different formats = credibility cascade.
```

### Problem #3: Mobile Scroll Distance to Primary CTA ✗
```
MOBILE (375px viewport height):

Height  │ Section              │ Content
────────┼──────────────────────┼──────────────────
  1VH   │ Hero                 │ Headline + 3 badges + CTAs
  2VH   │ Hero continued       │ Subheadline + trust row
  3VH   │ Hero Social Proof    │ 2 testimonials
  4VH   │ Niche Grid           │ 3 cards (stacked mobile)
  5VH   │ Approach             │ 3 cards (stacked mobile)
  6VH   │ Full Testimonials    │ 6 testimonials (stacked)
  7VH   │ PRIMARY CTA BAND     │ ← USER IS HERE AFTER SCROLLING 7X
  8VH   │ FAQ Teaser           │
  9VH   │ Footer CTA           │

PROBLEM: Mobile users scroll 7+ viewport heights to reach primary CTA.
Mobile attention: 55% of users don't scroll past 3-4 viewport heights.
Result: Users booking on mobile = LOWER than desktop.

SOLUTION: Add mobile sticky button
├─ Position: Bottom-right corner (16px padding)
├─ Size: 48px height (thumb-friendly)
├─ Text: "Book Free Call"
├─ Show: Only after scrolling past hero (don't cover hero CTA)
├─ Color: Sage green (#9dbf8d)
└─ Effect: +10-15% mobile conversion

MOBILE + STICKY BUTTON:
Height  │ Section              │ Content
────────┼──────────────────────┼──────────────────────
  1VH   │ Hero                 │ Headline + CTAs
  2VH   │ Social Proof         │ Testimonials
  3VH   │ Niches               │ 3 cards        [Book ▼] sticky
  4VH   │ Approach             │ 3 cards        [Book ▼] sticky
  5VH   │ Testimonials         │ 6 testimonials [Book ▼] sticky
  6VH   │ PRIMARY CTA          │ Booking CTA    [dismiss]
  7VH   │ FAQ Teaser           │ Collapsed FAQs
  8VH   │ Footer CTA           │ Secondary

EFFECT: Users ready to book don't need to scroll to section 6.
Easy reach on mobile (bottom-right button).
```
