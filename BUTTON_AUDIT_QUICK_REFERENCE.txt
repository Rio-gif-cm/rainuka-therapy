📝 NEW BUTTON API
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROPS (EnhancedButton)
──────────────────────────────────────────────────────────────────────────────
size?: 'xs' | 'sm' | 'md' | 'lg' | 'xl'       (new: xs, xl)
variant?: 'primary' | 'secondary' | 'outline' (secondary redesigned)
loading?: boolean                              (show spinner)
loadingText?: string                           (NEW: text during loading)
fullWidth?: boolean                            (NEW: width: 100%)
disabled?: boolean                             (improved styling)
type?: 'button' | 'submit' | 'reset'
onClick?: (e) => void
ariaLabel?: string
className?: string

SIZES
──────────────────────────────────────────────────────────────────────────────
xs │ 36px  │ 0.8125rem     │ 0.375rem 0.75rem   │ Chip buttons
sm │ 40px  │ 0.875rem      │ 0.5rem 1rem        │ Small CTAs
md │ 48px  │ 1rem (default)│ 0.875rem 1.75rem   │ Standard CTAs
lg │ 56px  │ 1.0625rem     │ 1rem 2rem          │ Large CTAs
xl │ 64px  │ 1.125rem      │ 1.25rem 2.5rem     │ Hero CTAs

VARIANTS
──────────────────────────────────────────────────────────────────────────────
primary   │ Sage-600 bg, white text      │ Main CTA (most urgent)
secondary │ Sage-50 bg, sage-700 text    │ Less urgent (NEW DESIGN)
outline   │ Transparent, sage-600 border │ Tertiary action

STATES
──────────────────────────────────────────────────────────────────────────────
hover    → transform: -2px lift + shadow expansion
focus    → 2px outline ring (white on primary, sage on others)
disabled → opacity: 0.5 + color shift + cursor: not-allowed
loading  → spinner animation + aria-busy="true"
