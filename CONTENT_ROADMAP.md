## 8. Content Quality Checklist (Per Piece)

Every published guide/blog post should meet:

- [ ] **Accuracy:** Clinically accurate, backed by research or personal expertise
- [ ] **Completeness:** Answers the core question fully (1,000+ words min)
- [ ] **Searchability:** Includes target keyword in title, H1, first 100 words
- [ ] **Scannability:** H2/H3 subheadings, bullet lists, short paragraphs
- [ ] **Actionability:** Includes at least 1 concrete step/exercise reader can do
- [ ] **Internal Links:** 3-5 links to other relevant content
- [ ] **CTA:** Clear booking/consultation link at end
- [ ] **SEO Metadata:** 
  - Title tag: 50-60 characters
  - Meta description: 150-160 characters
  - URL slug: keyword-rich, hyphens only
- [ ] **Frontmatter (for guides):**
  - title
  - description
  - date
  - readTime
  - category
  - keywords (4-6)
- [ ] **Proofread:** No typos, consistent formatting, active voice preferred

## 9. Risk Mitigation

### **Risk 1: Content Quality Inconsistency**
- **Mitigation:** Rainuka reviews every clinical piece; establish style guide
- **Owner:** Rainuka
- **Timeline:** Week 1 (create style guide)

### **Risk 2: Publishing Delays**
- **Mitigation:** Buffer weeks built in; prioritize TIER 1 ruthlessly
- **Owner:** Project manager (if assigned)
- **Contingency:** Reduce target by 20% if bandwidth constrained

### **Risk 3: Internal Link Failures**
- **Mitigation:** QA checklist for all links before publish
- **Owner:** Developer
- **Testing:** Broken link audit monthly

### **Risk 4: SEO Cannibalization**
- **Mitigation:** Define unique keyword focus per piece (avoid overlap)
- **Owner:** Content strategist
- **Prevention:** Content matrix (keyword → page mapping)

### **Risk 5: Outdated Information**
- **Mitigation:** Add "Last Updated" date to all guides; audit quarterly
- **Owner:** Web manager
- **Process:** Set calendar reminders for review dates
