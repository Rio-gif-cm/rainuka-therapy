PHASE 1: QUICK WINS (IMPLEMENTED ✅)

1. Hero Line-Width (Improvement #1)
   .prose-width-desktop { max-width: 65ch; }
   Impact: Improves readability (50-75 CPM optimal)

2. Button Sizing Variants (Improvement #2)
   btn-py-lg: 1.125rem (18px), btn-px-lg: 2rem (32px)
   Impact: Buttons grow 32px (mobile) → 56px (desktop primary)

3. Form Inputs Desktop Scale (Improvement #6)
   @media (min-width: 1024px) { input { padding: 1rem 1.25rem; } }
   Impact: Form inputs 32px → 48px+, labels 15px → 16px

4. Text Color Hierarchy (Improvement #8)
   .text-primary/secondary/tertiary/quaternary
   Impact: 4-tier system for visual scanning

5. Card Desktop Styling (Improvement #9)
   .card { padding: 2rem; box-shadow: stronger; }
   Impact: Cards gain breathing room on lg+

6. Enhanced Focus States (Improvement #10)
   3px outline + 6px ring on lg+ breakpoint
   Impact: WCAG 2.4.7 compliant keyboard navigation

7. Line-Height Optimization (Improvement #11)
   @media (min-width: 1024px) { p { line-height: 1.75; } }
   Impact: Long-form content easier to read
