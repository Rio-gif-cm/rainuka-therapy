================================================================================
CACHING STRATEGY OVERVIEW
================================================================================

NETWORK FIRST (API Calls)
  Route: /api/*
  Logic: Try network → Fallback to cache → Error message offline
  Benefit: Real-time data for bookings, forms always fresh

CACHE FIRST (Static Assets)
  Routes: Images (.svg, .png, .jpg, .webp, .gif), Fonts
  Logic: Return cached → If miss, fetch from network → Cache result
  Benefit: Instant load on repeat visits, 10-50x faster

STALE WHILE REVALIDATE (HTML Documents)
  Route: mode=navigate (HTML pages)
  Logic: Return cached immediately → Update in background
  Benefit: Perceived instant load, eventual freshness

RUNTIME CACHE (Scripts, Stylesheets)
  Route: JS/CSS files
  Logic: Cache First (rarely change)
  Benefit: Fast script loading on slow 3G
