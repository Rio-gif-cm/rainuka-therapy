## REFERRING DOMAIN DIVERSITY

- **Estimated external referring domains: 0-2** (all internal)
- **Internal referrals: ~5-7 (self-linking only)**

**Benchmark Comparison:**

| Authority Metric | Rainuka | Competitor | Gap |
|---|---|---|---|

**Ideal Diversity Mix (for 50-100 backlinks):**
```

Guest Posts:                  10-15 links (contributed content)
Mention/Citation Links:        8-12 links (resource pages linking to you)
Partnership Links:             5-8 links (collaborations, cross-promotions)
Local/Geographic Links:        5-8 links (local directories, chambers)
News/PR Links:                 3-5 links (press releases, media mentions)
Educational/Resource Links:    3-5 links (university resources, guides)
Unlinked Mentions:            20-30 links (tracked, brand mentions)
```

## TOXIC LINK DETECTION & REMOVAL

### Issue #20: No Toxic Link Audit or Disavow File
**Severity:** 🟡 **MEDIUM**  
**Impact:** Potential future penalty if toxic links acquired; no protection protocol.

**Current State:**
- No documented toxic link monitoring
- No disavow.txt file evident
- No backlink vetting process

**Toxic Link Red Flags to Monitor:**
1. **Spam directories** (with no editorial control)
2. **Negative SEO attacks** (competitors buying spam links to your site)
3. **Private blog networks (PBNs)** (artificial link farms)
4. **Link exchange schemes** ("link to us, we'll link to you")
5. **Paid/purchased links** (violates Google guidelines)
6. **Low-quality directories** (content farms, door pages)
7. **Unrelated niche links** (therapist link from gambling site)
8. **Exact-match domain anchor farms** (too many "adult ADHD therapy" anchors)

**Current Assessment:**
- **Risk Level: LOW** (few backlinks = low risk of toxic ones, but also low benefit)
- **Still required:** Implement monitoring protocol

**Action:**
1. Monthly monitoring of new backlinks (via Google Search Console, Ahrefs, SEMrush)
2. Disavow file created + ready for deployment if toxic links found
3. Process: If 3+ suspicious links acquired → add to disavow.txt
