## Audit Highlights

### Strengths
- **Variable font optimization:** Fraunces uses optical sizing axis (opsz); automatically refines strokes at display vs. small sizes
- **Accessible baseline:** Body text at 1.7 line-height (excellent for dyslexia), 16px minimum (mobile), with leading that increases as size decreases
- **Systematic scale:** Modular scale (1.25 ratio), semantic class names, all font sizes via CSS custom properties
- **Semantic h6:** Correctly uses sans serif for eyebrows/labels; all other headings are serif

### Issues Found (Now Fixed)
1. **h4 & h5 weight collision:** Both were 600; indistinguishable when nested → **Fixed: h4 now 500**
2. **h3 wrapping:** No max-width constraint; could orphan words on mobile → **Fixed: max-width 38ch**
3. **h4 wrapping:** Long labels didn't constrain; awkward breaks → **Fixed: max-width 40ch**
4. **Mobile heading leading:** 2–3 line headings on mobile felt cramped → **Fixed: h2 1.16→1.24, h3 1.24→1.32**

### Recommendations Still Pending
- Normalize paragraph spacing (10 min effort)
- Add `.type-micro-accessible` variant for critical small text (5 min)
- Validate clamp() ranges on extreme viewports (15 min)
- Add contrast validation test suite (20 min)
