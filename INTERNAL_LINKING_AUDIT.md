# Internal Linking Audit & Strategy
## Wonderloud Therapy Website

**Date:** September 1, 2026  
**Audit Type:** SEO-focused internal linking analysis  
**Focus:** Specialty pages → Booking, FAQ cross-linking, related content interconnection

---

## Executive Summary

The site has **good foundational linking** (homepage→booking, specialty FAQs with related links), but lacks **strategic interconnection** between:
- **Specialty pages** (adhd, perinatal, career, couples, etc.) → each other
- **FAQ pages** → specialty pages (they reference but don't link back)
- **Mid-funnel content** (parent, bipoc, lgbtq, etc.) → booking
- **Related specialty content** (e.g., ADHD+anxiety, perinatal+grief)

This hurts **SEO authority** (content silos), **user flow** (missed upsell opportunities), and **SERP density** (related pages don't reinforce each other).

## Link Architecture: Hub & Spoke Model

```
                          /booking
                             ▲
        /homepage ────────────┼────────────── /faq ──┬─── /adhd-faq
           ▲                  │                      ├─── /perinatal-faq
           │                  │
      [Niche Entry]      [Specialty Landing]
    /adhd /perinatal        /adhd ◄────────────────┘
    /career /couples         /perinatal
    /grief /bipoc           /career
    /lgbtq /parents         /couples
    /disability-access       /grief
    /financial-access        /parents
           │                  │
           └──────────────────┼─────────────────────┘
                              │
                    [Related Content Cross-Links]
                         (New links needed)
```

**Hub Pages** (high authority, high traffic):
- /homepage
- /booking
- /faq

**Spoke Pages** (specialty entry points):
- /adhd, /perinatal, /career, /couples, /grief
- /bipoc, /lgbtq, /men, /neurodivergent, /disability-access, /financial-access, /parents

**Strategy:**
- Spokes link **up** to hub (/booking)
- Spokes link **sideways** to related spokes (e.g., /adhd ← → /career)
- Hub **radiates out** to primary spokes
- **No orphaned pages**

## Technical Implementation Notes

### Link Best Practices
- **Anchor text:** Descriptive, not "click here" or "read more"
  - ✅ "Explore ADHD therapy for late diagnosis"
  - ❌ "Learn more"
- **Link placement:** Natural within body text, not random footer adds
- **No keyword stuffing:** Avoid linking same text 10x; vary anchors
- **Avoid link soup:** Max 3-5 internal links per section; quality > quantity

### Code Patterns (Next.js)
```tsx
// ✅ Good
<Link href="/adhd">
  ADHD therapy for late diagnosis and burnout
</Link>

// ❌ Avoid
<Link href="/adhd">click here</Link>
<Link href="/adhd">ADHD</Link> {/* too generic */}
```
