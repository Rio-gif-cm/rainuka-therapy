## 📊 Research Framework Used

All case studies validated against:

**Testimonial Psychology (from research):**
- Specificity > Vagueness (credibility through concrete details)
- Narrative Arc: Hook (pain) → Transformation (change) → Forward movement
- Trust Signals: Expertise + Trustworthiness + Contextual Understanding
- Functional Outcomes: Beyond symptom reduction (return to work, relationships, clarity)

**Therapeutic Credibility Literature:**
- Client credibility ratings predict therapy outcomes
- Perceived fit matters as much as modality
- Contextual understanding = trust

## ⚡ Key Quality Metrics

✅ **Authenticity:** Real therapy work language, not marketing-speak  
✅ **Warmth:** Rainuka's voice validates + explains + empowers  
✅ **Specificity:** Concrete before/after details (not generic praise)  
✅ **Narrative Arc:** Clear progression through Hook → Change → Forward  
✅ **Trust Signals:** All 3 present (expertise, trustworthiness, fit)  
✅ **Functional Outcomes:** Changes measured in life capacity, not symptom scales  
✅ **Partner Involvement:** Not therapist-centric; includes key people in each story  
✅ **Realistic Timelines:** Months, not weeks; integration, not "fixed"
