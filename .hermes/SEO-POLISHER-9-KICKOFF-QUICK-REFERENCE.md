## ⚠️ COMMON PITFALLS TO AVOID

### ❌ Keyword Stuffing
**Problem:** Forcing keywords ("ADHD therapy ADHD therapy...") breaks voice  
**Solution:** Use LSI keywords (synonyms), aim for 1-2% density, prioritize authenticity

### ❌ Incomplete Metadata
**Problem:** Contact page goes live without title/description (auto-generated by Google, low quality)  
**Solution:** Every page must have explicit metadata export

### ❌ Broken Redirects
**Problem:** Old URLs get 301→301→301 chains, hurting SEO  
**Solution:** Direct 301 redirects, test redirect chains before pushing

### ❌ Ignoring Mobile
**Problem:** Metadata optimizations look good on desktop, break on mobile  
**Solution:** Test all title/description lengths on mobile devices (48px narrower)

### ❌ Skipping Schema Validation
**Problem:** Schema markup has JSON errors, Google ignores it  
**Solution:** Always run Rich Results Test before committing schema
