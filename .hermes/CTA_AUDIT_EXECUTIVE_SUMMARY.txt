CRITICAL FINDINGS
================================================================================

7 Critical Gaps Identified:

1. STICKY MOBILE CTA - NO PERSISTENT CTA ON LONG PAGES
   Current: Users scroll to footer to book on /adhd, /career, /perinatal
   Impact: 15-20% conversion loss on mobile
   Solution: Add <StickyBookingCTA /> visible after 500px scroll

2. ABOVE-FOLD SATURATION - 3+ CTAS IN HERO
   Current: Homepage hero has Book + 3 personas + Explore = 5 paths
   Impact: Cognitive overload, decision paralysis
   Solution: Reduce to 1 primary CTA + 1 secondary link

3. BUTTON SIZE INCONSISTENCY - MIX OF PY-2/PY-3/PY-4
   Current: Buttons range from 32px-48px height
   Impact: WCAG accessibility violations, inconsistent UX
   Solution: Standardize all primary buttons to py-4 (48px minimum)

4. MOBILE TOUCH TARGETS - BELOW 44PX WCAG STANDARD
   Current: Some buttons < 44px height
   Impact: High mis-tap rate on mobile
   Solution: Enforce 48×48px minimum touch target on all platforms

5. MICROCOPY VARIANCE - INCONSISTENT BUTTON LABELS
   Current: "Book"/"Schedule"/"Get started"/"Learn more" mixed
   Impact: 5-8% conversion loss from cognitive friction
   Solution: Create microcopy.ts with 5 canonical labels

6. COLOR DILUTION - UNCLEAR SECONDARY BUTTON STYLING
   Current: Outline buttons insufficient contrast on tinted backgrounds
   Impact: Accessibility for colorblind users (8% population)
   Solution: Test colors on all background tints, enforce 4.5:1 minimum

7. SECTION CTA GAPS - MISSING CTAS BETWEEN CONTENT
   Current: Long pages end sections abruptly, user must scroll to footer
   Impact: Reduced engagement, scroll fatigue
   Solution: Add sage-50 section with CTA after major content blocks
