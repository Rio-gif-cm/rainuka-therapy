## 📊 Visual Hierarchy Summary

### By Impact Level

```
┌─────────────────────────────────────────────────────────┐
│ HIGHEST IMPACT (Primary Entry Point)                    │
│ ─────────────────────────────────────────────────────── │
│ • Photo Hero (1600x1000px, 40% opacity)                 │
│ • Handwritten "Trauma-Informed" (5xl-7xl, Caveat)      │
│ • Immediate visual differentiation                      │
├─────────────────────────────────────────────────────────┤
│ MEDIUM-HIGH IMPACT (Trust Building)                     │
│ ─────────────────────────────────────────────────────── │
│ • Video Testimonials (play-on-scroll)                   │
│ • Niche Illustrations (120x120px SVG)                   │
│ • Social proof + visual storytelling                    │
├─────────────────────────────────────────────────────────┤
│ MEDIUM IMPACT (Personal Touch)                          │
│ ─────────────────────────────────────────────────────── │
│ • Testimonial Avatars (48px circles + initials)        │
│ • Handwritten font accents (section headers)           │
│ • Builds familiarity + warmth                          │
├─────────────────────────────────────────────────────────┤
│ SUBTLE IMPACT (Atmospheric)                             │
│ ─────────────────────────────────────────────────────── │
│ • Ambient photo backgrounds (15-25% opacity)           │
│ • Page dividers with photo accents                      │
│ • Supports copy without distraction                     │
└─────────────────────────────────────────────────────────┘
```
