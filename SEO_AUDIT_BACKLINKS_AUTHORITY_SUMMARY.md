## INTERNAL LINK ARCHITECTURE FIXES

### Current Problems
- Specialties don't link to each other (siloed)
- No hub pages centralizing link equity
- ADHD page doesn't link to ADHD-FAQ
- Homepage doesn't emphasize internal linking
- Related content not cross-linked

### Solution: Hub-Spoke Model
```
Homepage (HUB)
  ├─→ Specialties Hub (NEW)
  │    ├─→ /perinatal
  │    ├─→ /adhd  
  │    └─→ /career
  ├─→ Guides Hub
  ├─→ FAQ Hub
  └─→ Top resources

Each specialty links back to hub + to other specialties.
All clustered content links to pillar pages.
```

### Anchor Text Fix
**Before:** 80% exact match keywords (unnatural)
**After:** 
- 20% exact match ("Adult ADHD therapy")
- 30% partial match ("ADHD diagnosis help")
- 20% branded ("Rainuka ADHD services")
- 30% generic ("Learn more," "Read more")
